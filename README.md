# বাজার দর / BazarDor

BazarDor is a modern, responsive web application designed to help users track, check, and compare the daily updated prices of essential daily commodities like groceries, vegetables, meat, and fish in local markets.

## 5 Key Features of the Project
1. **Daily Price Tracking:** View real-time average, highest, and lowest prices of daily commodities.
2. **Category & Sorting:** Filter products by categories and sort prices (Low to High / High to Low) handling Bengali numerals accurately.
3. **Market-wise Summary:** Detailed product pages showing price variations across different local markets.
4. **Secure Authentication:** User sign-in and sign-up functionality using Better Auth (including social logins).
5. **Profile Management:** A dedicated user profile route with a form to update user information dynamically.

## Technologies Used
* **Frontend:** Next.js (App Router), React, TypeScript
* **Styling:** Tailwind CSS, DaisyUI
* **Authentication:** Better Auth
* **Deployment:** Vercel
